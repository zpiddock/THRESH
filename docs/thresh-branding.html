05 // Guidelines
Usage Rules
✓ Do
  • Always render the Ξ in cyan when color is available
  • Use "THRΞSH" in all-caps for the logotype
  • Use "thresh" lowercase for code references, CLI, filenames
  • Maintain clear space around the logotype
  • Use dark backgrounds as the primary context
  • Allow the logotype to breathe — minimal surrounding elements
✗ Don't
  • Don't render the Ξ in the same color as the rest of the mark
  • Don't use mixed case ("Thresh", "ThResh")
  • Don't rotate, skew, or distort the logotype
  • Don't add drop shadows, bevels, or 3D effects to the type
  • Don't place on busy backgrounds without sufficient contrast
  • Don't substitute Ξ with "E" when unicode is available
